# ANALYTICS ENGINE SKILL

Generate insights from user behavior.

Insight Types:

Spending Trends
Savings Trends
Budget Risks
Goal Forecasting

Examples:

* Food spending increased 18%.
* Transport spending increased 3 months consecutively.
* Goal completion projected in 5 months.

Requirements:

Insights must be:

* explainable
* deterministic
* testable

No AI required for MVP.
Use rules-based analytics engine.
