# SUPABASE ENGINEER SKILL

Use Supabase for:

* Auth
* PostgreSQL
* Realtime
* Storage

Requirements:

* Row Level Security on every table.
* UUID primary keys.
* Audit timestamps.
* Soft delete support.

Every table must include:

created_at
updated_at

Security:

Users may only access their own records.

Never disable RLS.

Generate:

* SQL migrations
* Policies
* Indexes
* Triggers
