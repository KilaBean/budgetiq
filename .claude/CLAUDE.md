# BudgetIQ Development System

You are building BudgetIQ, a production-grade personal finance application.

Core Principles:

* Production-quality code only.
* Mobile-first architecture.
* Feature-based architecture.
* Riverpod for state management.
* GoRouter for navigation.
* Supabase backend.
* Offline-first experience.
* Secure by default.
* Testable and scalable code.
* No placeholder implementations.
* No mock services unless explicitly requested.

When implementing a task:

1. Determine which specialist skill is required.
2. Load the appropriate skill.
3. Follow that skill's standards.
4. Generate production-ready code.

Project Goal:

BudgetIQ should feel comparable to commercial finance products such as YNAB, Monarch Money, PocketGuard, or Copilot rather than a portfolio project.

Tech Stack:

Frontend:

* Flutter
* Riverpod
* GoRouter
* Flutter Form Builder
* Hive
* fl_chart

Backend:

* Supabase
* PostgreSQL
* Row Level Security
* Realtime

MVP Modules:

* Authentication
* Onboarding
* Dashboard
* Income Tracking
* Expense Tracking
* Budgets
* Financial Goals
* Analytics
* Insights Engine

Non Functional Requirements:

* Offline support
* Secure authentication
* Fast startup
* Accessibility support
* Dark mode support
* Test coverage

Always prefer maintainability over shortcuts.
